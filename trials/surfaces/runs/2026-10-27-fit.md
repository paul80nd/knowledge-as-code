# Fit of each unused surface, 2026-10-27

This reading takes each surface the [2026-10-27 reading](2026-10-27.md) shows unused, and asks whether an example
corpus has a natural place for it. A fit uses a fact the corpus already states. Where a value would have to be
invented, the surface has no fit. [#1165](https://github.com/paul80nd/knowledge-as-code/issues/1165) starts from what
is left.

A corpus is one repository of knowledge records. A record is one Markdown document in it, with a declared type.

Read from `main` at `76bc68189`. A `_template.md` is a seed, so its values count for nothing here.

## Flags a corpus pipeline could use

The template's pipelines run `validate --since`, `generate --check`, `export` and `bundle`. The other flags serve
whoever maintains a corpus or the framework, so a pipeline has no use for them.

| Flag                | Verdict    | Why                                                                                     |
|---------------------|------------|-----------------------------------------------------------------------------------------|
| `update --check`    | No fit now | It fetches the template over the network on every run.                                  |
| `report --out`      | No fit now | A report record has judgement columns a person answers, so a pipeline cannot write one. |
| `pack --repository` | No fit now | Only a publish workflow packs, and the template ships none (#1013).                     |
