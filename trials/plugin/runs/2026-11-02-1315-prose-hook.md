# The prose arm through hooks

**Every page reached every session whole, and every compliance verdict matched the prose arm staged the old way.**
Three `examples/engineering` cases ran twice each in the prose arm, once with the cut in `append_system_prompt` and once
with the same cut printed by five `SessionStart` hooks. All 12 sessions did the task, and all 12 graded the same on
compliance. Citation moved by one session, from 3 of 6 the old way to 4 of 6 the new way.

[Story #1315](https://github.com/paul80nd/knowledge-as-code/issues/1315) moves the prose arm onto hooks, because the
adopting corpus's pilot showed that Windows refuses a command line over 32,767 characters. Its three prose sessions
failed at spawn with `ENAMETOOLONG`. This run checks the new delivery on macOS before a Windows run relies on it.

## Setup

| Item          | Value                                                                                         |
|---------------|-----------------------------------------------------------------------------------------------|
| Corpus        | `examples/engineering` 0.48.0, from `kac export` and `kac bundle`                             |
| Cases         | `house/pricing-call`, `house/health-endpoint` and `house/request-logging`                     |
| Prose text    | a cut of 40,057 characters: the export's opening lines and its whole `standards` section      |
| Old           | `main`'s `stage.sh`, with each prose `case.yaml` rewritten to append the cut                  |
| New           | this branch's `stage.sh`, given the cut as its fourth argument, which wrote 5 pages           |
| Arm           | prose only, `--ablation none`, `--runs 2`, `--allow-tools Write Edit`, as on Windows          |
| Model         | `claude-opus-5-5`, on Claude Code 2.1.309                                                     |

The whole prose text of `examples/engineering` is 178,288 characters, which the new `stage.sh` splits into 22 pages.
The cut matches the size of the adopting corpus's, 39,776 characters.

| `health-endpoint` |   2 | pass, pass, fail        | pass, pass, pass        |

| `pricing-call`    |   2 | pass, pass, fail        | pass, pass, fail        |
| `request-logging` |   1 | pass, pass, pass        | pass, pass, pass        |
| `request-logging` |   2 | pass, pass, pass        | pass, pass, pass        |

A set of alternatives passes where one of them does, as [Writing a case](../README.md#writing-a-case) says. No session
fired a lookup, because the prose arm has none.

**Every page arrived.** Each new session's transcript has five `hook_success` attachments from `SessionStart`, one per
page. Each attachment's `content` is its page's whole text, less the final newline. The largest page was 9,390
characters, under the cap. The pages arrived in a different order in five of the six sessions, so the `Page <n> of <m>.`
header each page begins with is needed.

## Cost

The old way cost USD 2.05 and the new way USD 1.99, list price, for 6 sessions each.

## What it changes

The prose arm runs on Windows. The text now arrives as context in the conversation, as a `CLAUDE.md` does, so
`method` moves to 8. Six sessions a way cannot show a difference smaller than one session, so the next run that reads
the prose arm reads it at method 8 alone.
