## What the reviews show

* **The relay loses the id.** A forked skill's report reaches the asking session as a tool result, and the session
  rewrites it for the person. Every report cited each finding by id. Two of the three `should-departure` replies cited
  no id at all.
* **The reviewer judges the change, and `std-DEPLOY` is about the artefact.** No report connected a new health
  endpoint to "An artefact **MUST** record the commit it was built from". Each report left the build and the
  pipeline alone, because the change did not touch them, and two said so of older gaps in the same files.
* **The reports keep to the skill's shape.** Each opened on the change and the fixed point, gave Violations, Judgement
  calls and Not in force, quoted the obligation, linked the rule, quoted `generatedAt`, and closed on the corpus
  searched and the rules left to an automated control.
* **`git` does not run in the eval sandbox on macOS.** Every session found the `xcrun` shim blocked. Three read the base
  files from `.git/objects`, one pointed `TMPDIR` at a writable folder, and one ran git from the Command Line Tools
  path. One, `health-endpoint/3`, reviewed the changed files whole, with no base to compare them against.
* **A wrong fixed point stops the review.** In `health-endpoint/2` the session passed `main`, which the repository does
  not have. The subagent stopped, as the skill says, and the session called it again with `master`.

## What the result does not show

* **Whether a review cites better where the session relays the report whole.** No run asked for that.
* **Whether a reviewer finds a MUST the change itself breaks.** The `health-endpoint` fault is an omission the change
  inherits, and no case has a change that breaks a MUST in the lines it adds.
* **The skill as committed.** After the run, the skill gained the table of a rule line's keys and a section on each
  unsettled status, which `PluginSkillFieldTests` and `PluginSkillStalenessTests` require of every skill reading a
  type. The instructions on the change, the keywords, the controls and the report did not move.
* **Anything about a corpus with an enforcing control.** Every control in `examples/engineering` is `not-enforced`, so
  no review had a rule to leave out.

Three runs a case is a small sample.
