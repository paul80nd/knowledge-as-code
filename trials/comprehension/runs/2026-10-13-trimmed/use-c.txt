U05. No. CI never commits: `generate --check` lists the stale files and exits 1 without writing anything, and the job should have read-only permission. Run `kac generate` on your own machine and commit what it writes.

U08. Exit code 2 means no corpus was found, not a fault in one: the step ran outside a corpus, with no `.corpus.yaml` above the working directory. `cd` into the corpus and run it again.

U13. No. Below 1.0.0 a caret admits only the same minor version, so `^0.16.0` never takes `0.17.0`. Change the range to `^0.17.0` and commit the rewritten `resolved` line with it.

U14. `pack` rebuilds its output folder whole, so the folder now holds only the new version, and `restore` refuses a consumer still locked to the earlier one. Move the lock along with the range to match the producer's new `content-version`, or delete `resolved:` and restore again.
Page: cli/restore.md
