# Library: 21 October 2026

This run is #991. It asked the three questions in [`library.yaml`](../questions/library.yaml) of `examples/library`, a
corpus (one repository of knowledge records) read as a wiki. It measures the three scenarios in
[`learn.feature`](../../use-cases/learn.feature). The set scored 8 of 9, and every scenario met its threshold. Two of
three readers still answered "Yes" when asked whether a borrower can reserve from another branch today.

## Setup

| Item            | Value                                                                                                |
|-----------------|------------------------------------------------------------------------------------------------------|
| Corpus at       | `3779317b` on `991-library-comprehension`, the files git tracks under `examples/library`             |
| Model           | `claude-opus-5-5`, for every reader                                                                  |
| Readers per set | Three, A, B and C, each a `general-purpose` agent with its own staged copy and no other context      |
| Prompt          | The one in [the README](../README.md#the-prompt), with the `library.yaml` row                        |
| Answers         | Each reader's reply, verbatim, under [`2026-10-21-library/`](2026-10-21-library/)                    |

Each reader was given only the `id` and `question` of each entry. The corpus has no `index.md`, so the prompt starts
the reader at `README.md`.

A citation counts where the `Page:` line names the record's file, or where the reply gives the record's id.

### How L03's partials were scored

The key names two partial cases: the fee without the status, and the status without the offering. Neither fits
readers A and B, so the session that ran the readers scored them under step 4 of
[Running the trial](../README.md#running-the-trial). Each answer leaves out a part the key asks for: the question asks
about today, and the key's answer to that is "Not yet".

* **Reader A** opened with "Yes", and then said the offering is still being built. It gave the status and contradicted
  it in the same answer.
* **Reader B** opened with "Yes". It said nothing links to production yet, and that borrowers "may not be able to reach
  it today". It never said the offering is being built.

Both scored partial. Each gave the offering and the fee correctly, and each answered "today" wrongly.

## The scenarios in learn.feature

The offering scenario passes on its literal wording. Readers A and C each said the offering is still being built, and
cited `ofr-reservations`. Reader B did not say it. Two of three readers nonetheless answered "Yes" to "today", so the
scenario's `Then` passes an answer that gets the question wrong.

## What the run shows

* **The glossary and the explanation each gave every reader the answer.** All three readers found both records, and
  each answered in the record's own terms.
* **`ofr-reservations` states its status away from its opening.** The record opens in the present tense: "A borrower
  places a hold on an item held at another branch, pays the fee...". It states that the offering is building only in
  the badge, the frontmatter and Known limitations. Readers A and B answered from the opening, and reached "Yes".
* **A reader read about a twentieth of the corpus.** Each reader read from 2,083 to 2,245 words of 37,838.

## What the run does not show

* **No comparison arm.** The run measured one corpus once, so it shows no change caused by any edit.
* **A three-question set is small.** One answer moves the set score by a ninth.
* **This run is the baseline.** A later run after a change to `examples/library` is compared against it, under
  [the pass rule](../README.md#the-pass-rule).
