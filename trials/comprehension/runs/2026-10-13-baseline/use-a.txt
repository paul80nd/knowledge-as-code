U13. No. Below 1.0.0, `^0.16.0` admits only the same minor version, so it will not take 0.17.0, and `restore` never tells you a newer version exists. To take it, edit `version` to `^0.17.0` and the entry re-resolves on the next run.
Page: cli/restore.md

U14. A folder holds only the version packed last, and the consumer's `resolved:` lock still names the old version, so `restore` refuses because the folder has no package for it. Move the lock along with the range when the producer's `content-version` moves, or delete `resolved:` and let the next restore write it.
Page: cli/restore.md

U15. No. Before a restore, `export` writes nothing and stops with "nothing is restored for <shortcode> ... Run kac restore". An export always carries the corpora it consumes, and a consumer cannot leave out what it inherits.
